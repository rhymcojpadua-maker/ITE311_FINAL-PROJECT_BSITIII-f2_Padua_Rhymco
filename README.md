# SweetCrumbs: Online Cake Ordering and Management System

Student Name: Rhymco J. Padua
Course and Section: BSIT III-F2

**Project Description:** 
A Software as a Service (SaaS) cake ordering and management platform that allows cake shop businesses to create and manage their online stores. The platform enables customers to browse cake products, view prices, place orders, and select their preferred pickup or delivery dates. Business owners can manage their products, prices, inventory, and customer orders through the system.

Technologies Used: HTML, CSS, JavaScript, Git, GitHub
